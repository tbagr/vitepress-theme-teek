手机有新版本的系统，但是没有更新到最新版本，但是又想保留ROOT权限，那么可以通过OTA升级系统，然后保留ROOT权限。

## 1. 升级前的准备

> **备份 `init-boot` 文件**

1. 手机MT管理器中, `/dev/block/by-name` 目录下有 `init-boot-a` 和 `init-boot-b`

2. 根据当前系统所在分区, cv对应的 `init-boot` 到 `sdcard` 根目录下, 并重命名为 `init-boot.img`

3. 同时以防万一, 备份到电脑上, 用以 重启时忘记 `Magisk` 中 `安装到未使用的槽位(OTA后)` 可能导致的无法开机时, `fastboot模式` 恢复系统镜像文件

## 2. 全量升级系统

1. 在手机上 `设置` -> `系统与更新` -> `软件更新` -> `检查更新` 查看是否有新版本系统

2. 如果有新版本，大小应该在8GB左右，点击 `下载与安装`

3. 出现 `重启系统` 时, 需要先进 `magisk` 里面, 在 第一个 `Magisk` 卡片中点击右侧安装按钮, 选择 `安装到未使用的槽位(OTA后)` 并点击 `开始`

4. 安装完成后, 回到系统OTA升级界面, 点击 `重启系统` (重启到 `新分区` )

5. 如果无新版本, 左上角 `尝鲜申请` 试一下

## 3. 增量升级系统

1. 在手机上 `设置` -> `系统与更新` -> `软件更新` -> `检查更新` 查看是否有新版本系统

2. 如果有，大小应该在几百MB左右，点击 `下载与安装`

3. 出现 `重启系统` 时, 点击 `重启系统` (系统补丁, 重启到 `原分区` )

4. 如果无新版本, 左上角 `尝鲜申请` 试一下
